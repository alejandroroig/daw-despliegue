# DAW — Despliegue de Aplicaciones Web

Repositorio de trabajo del módulo.

## Contenido

- `escaparate/`: aplicación utilizada durante las prácticas.
- `practicas/`: configuraciones y procedimientos de despliegue.
- `docs/`: documentación.
- `entregas/`: actividades entregadas.

## Requisitos

- Git.
- El resto de herramientas se incorporará durante el curso.

## Flujo de trabajo

Cada sesión se trabaja en una rama `sesion-NN`.

Los cambios llegan a `main` mediante Pull Request.
